# Video Learning System

企业项目脱敏后的公开演示版。保留视频学习业务中的前端交互与状态处理，所有接口、账号、表结构和业务数据均已替换为本地 Mock。

## 功能

- HTML5 Video 播放器：播放、暂停、拖拽、音量、倍速和全屏
- 断点续播：三秒节流保存，暂停和离开页面时补充保存
- 匿名进度：使用 `localStorage` 持久化演示数据
- 点赞收藏：乐观更新，模拟接口失败后自动回滚
- 评论：内容校验、异步发布和列表更新
- 每日练习：答案缓存、进度恢复和结果统计
- 学习记录与周学习概览

## 技术

JavaScript ES6+、HTML5 Video、CSS3、Fetch/Promise 风格 Mock API、localStorage、响应式布局。

## 运行

直接打开 `index.html`，或使用静态服务器：

```bash
npx serve .
```

## 脱敏说明

- 不包含企业名称、域名、内部页面地址或数据库表名
- 不连接生产接口，不包含真实账号和用户数据
- 视频使用 Google 公共示例资源，仅用于播放器演示
